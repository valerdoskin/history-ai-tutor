**Промт:**

>
> 1. Прочитай ВСЕ JSON из `output/` (кроме report.json) — один раз.
> 2. Для каждого параграфа сформируй промт для DeepSeek, который извлекает:
>    - даты и события (для хронологии);
>    - персоналии (имя, годы жизни, роль);
>    - термины и понятия (с определениями);
>    - причинно-следственные связи (причина → следствие);
>    - ключевые факты для ОГЭ/ЕГЭ;
>    - типовые вопросы ОГЭ/ЕГЭ по теме;
>    - привязку к кодификатору ФИПИ (код темы).
> 3. Сохрани результат в `knowledge/enriched.json` (единый файл).
> 4. Добавь логирование прогресса (каждый 10-й параграф) и обработку ошибок с ретраями.
>
> **Правила против зацикливания:**
> - НЕ перечитывай `output/*.json` повторно — загрузи их один раз в память.

>   (title, number, page_start, page_end, main_question, terms, sync_table,

## Этап 3: Разбиение на чанки для RAG

**Промт:**

> Создай скрипт `scripts/chunking.py`, который разбивает обогащённые параграфы
> из `knowledge/enriched.json` на чанки для RAG. Выполни за ОДИН проход:
>
> 1. Прочитай `knowledge/enriched.json` — один раз.
> 2. Для каждого параграфа создай чанки:
>    - теория — по разделам/абзацам (НЕ весь параграф целиком);
>    - каждый спецблок — отдельный чанк;
>    - синхронистические таблицы — отдельные чанки;
>    - ключевые элементы (даты/термины/персоналии) — отдельные чанки-справочники.
> 3. Добавь перекрытие чанков (overlap ~100–200 символов).
> 4. Добавь метаданные к каждому чанку: book_id, class, chapter, paragraph,
>    section, type, page_start, page_end, fipi_codes, dates, figures, terms.
> 5. Сохрани чанки в `knowledge/chunks.json`.
> 6. Построй BM25-индекс (rank_bm25) и сохрани в `knowledge/bm25_index.pkl`.
>
> **Правила против зацикливания:**
> - НЕ перечитывай `enriched.json` повторно — загрузи один раз.
> - НЕ анализируй структуру параграфа заново — она уже известна.
> - Если чанк получился пустым — пропусти его, не пытайся «исправить».
> - Выполни все 6 пунктов за один запуск скрипта.
