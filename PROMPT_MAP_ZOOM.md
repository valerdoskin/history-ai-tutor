# Промт: Увеличение исторических карт (zoom) в веб-интерфейсе

> **Дата:** 2026-09-04
> **Цель:** чтобы ученик мог **увеличивать историческую карту** в вопросах типа `map`
> (и в любом другом месте, где показывается карта), чтобы рассмотреть мелкие детали
> (названия, границы, направления походов). Сейчас карта показывается статично и
> увеличивать её нельзя.

---

## Проблема (диагноз уже поставлен, НЕ перепроверять)

Карты отображаются в веб-интерфейсе как обычное статичное изображение без возможности
увеличения. Ключевые факты:

- В `static/webapp.js` функция **`mapImageHtml(q)`** (строка ~164) генерирует разметку карты:
  ```js
  function mapImageHtml(q) {
      if (!q || !q.image) return '';
      return `<div class="map-image-wrap"><img class="map-image" src="${q.image}" alt="Историческая карта" loading="lazy"></div>`;
  }
  ```
- Эта функция вызывается в **5 местах** рендера вопросов (строки ~179, 206, 315, 859, 1030):
  ОГЭ с вариантами, развёрнутые ответы, тренировка по типам, полноценный тест и т.д.
  Значит, если добавить zoom в `mapImageHtml`, он заработает **везде**, где показывается карта.
- В `static/webapp.css` класс `.map-image` (строка ~853) имеет:
  ```css
  .map-image {
      max-width: 100%;
      max-height: 420px;
      border-radius: 8px;
      border: 1px solid #333;
      box-shadow: 0 2px 8px rgba(0, 0, 0, 0.4);
  }
  ```
  Карта ограничена по высоте 420px и не увеличивается.
- В проекте **нет ни одного модального окна / lightbox / zoom-логики** (проверено: в
  `webapp.css`, `webapp.js`, `webapp.html` нет `modal`, `lightbox`, `overlay`, `zoom`).
- Проект работает **без внешних библиотек и внешних источников** (принцип проекта).
  Значит, zoom нужно реализовать на чистом JS/CSS, без CDN-библиотек.

## Файлы, которые нужно менять (только их)

1. `templates/webapp.html` — добавить разметку модального окна (overlay) в конец `<body>`
   (перед `<script src="/static/webapp.js">`).
2. `static/webapp.js` — логика: сделать карту кликабельной, открытие/закрытие модального
   окна, зум (+/−/сброс), панорамирование (drag), закрытие по клику на фон и по Esc.
3. `static/webapp.css` — стили модального окна, кнопок зума, панорамирования (в тёмной теме
   проекта, цвета `#1a1a2e`, `#16213e`, `#e94560` и т.д.).

## Варианты решения (выбрать и согласовать с пользователем)

### Вариант A (рекомендуемый): Lightbox-модальное окно с зумом и панорамированием
- Клик по карте (или по кнопке «🔍 Увеличить») открывает **полноэкранное модальное окно**
  (тёмный overlay поверх всего приложения) с увеличенной картой по центру.
- Внутри модального окна:
  - кнопки **«+» / «−»** для приближения/отдаления;
  - кнопка **«⟲ Сброс»** для возврата к исходному масштабу;
  - кнопка **«✕»** (и клик по фону, и клавиша **Esc**) для закрытия;
  - **колесо мыши** — зум (приближение к курсору);
  - **drag мышью / пальцем** — панорамирование (перемещение по увеличенной карте);
  - **pinch (двумя пальцами)** на мобильных — зум.
- Реализация на чистом JS/CSS, без внешних библиотек.
- **Плюсы:** полноценный просмотр карты, удобно на ПК и мобильном, работает во всех местах
  через `mapImageHtml`.
- **Минусы:** больше кода (нужна аккуратная обработка зума/панорамирования и touch-событий).

### Вариант B: Простое увеличение при наведении (hover zoom)
- При наведении курсора карта увеличивается (CSS `transform: scale`).
- **Минусы:** не работает на мобильных (нет hover); неудобно для детального изучения
  (карта «уезжает» под курсор); нет панорамирования.

### Вариант C: Открытие карты в новой вкладке
- Клик по карте открывает `/static/maps/<файл>.png` в новой вкладке браузера.
- **Минусы:** уводит ученика из приложения; в новой вкладке нет зума/панорамирования
  (только встроенный зум браузера); неудобно на мобильных.

## Что нужно сделать для Варианта A (если он выбран)

### Шаг 1. Разметка модального окна в `templates/webapp.html`
Добавить в конец `<body>` (перед `<script src="/static/webapp.js">`) разметку overlay:
- `<div id="map-lightbox" class="map-lightbox" hidden>` — полноэкранный overlay;
  - внутри: `<div class="map-lightbox-toolbar">` с кнопками «+», «−», «⟲», «✕»;
  - `<div class="map-lightbox-viewport">` — область просмотра (overflow hidden), внутри
    `<img id="map-lightbox-img" class="map-lightbox-img">`, который будет масштабироваться
    и перемещаться.
- Кнопки должны иметь `data-action` (zoom-in / zoom-out / reset / close) для делегирования
  событий в JS.

### Шаг 2. Логика в `static/webapp.js`
- **Сделать карту кликабельной:** в `mapImageHtml(q)` обернуть карту в кликабельный элемент
  (например, добавить кнопку-подсказку «🔍 Увеличить» под/над картой и обработчик клика по
  `.map-image`). Карта должна открывать lightbox по клику.
- **Открытие:** по клику на карту — показать overlay (`hidden` → убрать), установить
  `src` увеличенной карты в `#map-lightbox-img`, сбросить масштаб/позицию к исходным.
- **Зум:** кнопки «+»/«−» и колесо мыши меняют `scale` (например, от 1 до 8, шаг ~0.25–0.5).
  При зуме колесом — приближать к точке под курсором (смещать позицию так, чтобы точка
  под курсором оставалась на месте).
- **Панорамирование:** drag мышью/пальцем по viewport перемещает карту (изменение
  `translateX/translateY`). Ограничить перемещение, чтобы карту нельзя было «утащить»
  полностью за край (по возможности).
- **Сброс:** кнопка «⟲» возвращает `scale=1`, `translate=0`.
- **Закрытие:** кнопка «✕», клик по фону overlay (вне карты), клавиша **Esc**.
- **Touch (мобильные):** поддержать pinch (два пальца) для зума и drag одним пальцем для
  панорамирования. Использовать Pointer Events или touch-события.
- **Делегирование:** повесить один обработчик на overlay (для кнопок и клика по фону),
  чтобы не плодить обработчики.

### Шаг 3. Стили в `static/webapp.css`
- `.map-lightbox` — фиксированный overlay на весь экран (`position: fixed; inset: 0;
  background: rgba(0,0,0,0.85); z-index: 1000; display: flex; flex-direction: column;`).
- `.map-lightbox-toolbar` — панель кнопок (зум/сброс/закрыть), стилизовать в тёмной теме
  проекта (кнопки с фоном `#16213e`, акцент `#e94560`).
- `.map-lightbox-viewport` — область просмотра (`flex: 1; overflow: hidden; position: relative;
  cursor: grab;`), при drag — `cursor: grabbing`.
- `.map-lightbox-img` — карта внутри viewport (`position: absolute; transform-origin: center;
  user-select: none; -webkit-user-drag: none;`), масштаб/позиция задаются через
  `transform: translate(x,y) scale(s)`.
- Кнопка-подсказка «🔍 Увеличить» над картой в `.map-image-wrap` (небольшая, полупрозрачная,
  появляется при наведении на ПК и всегда видна на мобильных).

### Шаг 4. Проверка
- Открыть тренировку по картам (вкладка «Практика» → «🗺️ Карты») и полноценный тест —
  карта должна открываться в lightbox по клику.
- Проверить зум кнопками и колесом мыши, панорамирование drag, сброс, закрытие (✕, клик по
  фону, Esc).
- Проверить на мобильном (pinch-зум, drag пальцем).
- Убедиться, что другие типы вопросов (culture, source и т.д.) не сломались.

## Критерии приёмки

1. Клик по карте открывает полноэкранное модальное окно с увеличенной картой.
2. Работают кнопки «+»/«−» (зум), «⟲» (сброс), «✕» (закрыть), закрытие по клику на фон и Esc.
3. Работает зум колесом мыши (приближение к курсору) и панорамирование drag мышью.
4. На мобильных работает pinch-зум и панорамирование пальцем.
5. Zoom работает во всех местах, где показывается карта (через `mapImageHtml`), не ломая
   другие типы вопросов.
6. Реализация на чистом JS/CSS, без внешних библиотек и внешних источников.
