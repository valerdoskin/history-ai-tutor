# Парсер учебников истории (history-ai-tutor)

Парсер извлекает структурированный контент из DOCX- и PDF-учебников истории
для создания ИИ-репетитора (по аналогии с english-ai-tutor).

Основной формат — **DOCX** (конвертированные из PDF через Adobe Acrobat).
PDF-обработка сохранена как **fallback** для будущих файлов.

## Возможности

- **Главы и параграфы** — определяет заголовки глав и параграфов (§) с номерами страниц.
- **Главные вопросы** — извлекает главный вопрос каждого параграфа.
- **Разделы** — выделяет нумерованные разделы внутри параграфов.
- **Специальные блоки** — распознаёт и сохраняет все специальные блоки:
  - исторический портрет;
  - свидетельство эпохи;
  - любопытные детали;
  - работа с хронологией;
  - работа с источником;
  - работа с понятиями;
  - подведём итоги;
  - вопросы и задания;
  - дополнительные материалы;
  - итоги главы;
  - вопросы и задания к главе.
- **Ключевые элементы** — извлекает по форматированию шрифта:
  - **даты** — полужирный шрифт;
  - **термины** — курсив;
  - **персоналии** — полужирный курсив.
- **Синхронистические таблицы** — сохраняет таблицы «Россия — Мир».
- **Текст не сокращается** — всё содержимое сохраняется в исходном виде.
- **Очистка артефактов** — автоматически удаляет символы-артефакты извлечения
  из PDF-шрифтов (например, `\uf401`), не искажая текст.

## Установка

```bash
pip install -r requirements.txt
```

## Структура проекта

```
history-ai-tutor/
├── books/                        # DOCX- и PDF-учебники
├── base_docx_parser.py           # Единая основа DOCX-парсера (класс BaseDocxParser)
├── parsers.py                    # Специализированные парсеры для каждой книги + реестр
├── docx_parser.py                # Оригинальный DOCX-парсер (однофайловая версия)
├── parser.py                     # PDF-парсер (fallback)
├── batch_processor.py            # Пакетная обработка всех учебников
├── test_parser.py                # Тестовый скрипт
├── config_russia_history.json    # Конфигурация для истории России
├── config_world_history.json     # Конфигурация для всеобщей истории
├── requirements.txt              # Зависимости
└── README.md                     # Документация
```

## Использование

### Обработка одного учебника

```bash
# DOCX (основной парсер)
python docx_parser.py books/6_klass._Istoriya_Rossii.docx config_russia_history.json output.json

# PDF (fallback)
python parser.py books/6_klass._Istoriya_Rossii.pdf config_russia_history.json output.json
```

### Пакетная обработка всех учебников

```bash
python batch_processor.py
```

Скрипт автоматически обработает все DOCX-файлы из папки `books/`, подберёт
конфигурацию и специализированный парсер по имени файла и сохранит результаты
в папку `output/` с отчётом `report.json`.

**PDF — только fallback.** PDF-файл обрабатывается лишь для книг, у которых
нет DOCX-версии. Если для книги есть DOCX, соответствующий PDF пропускается
(DOCX — основной и более точный формат).

Дополнительные параметры:

```bash
python batch_processor.py --books-dir books --output output --report report.json
```

### Тестирование парсера

```bash
# Быстрый тест (проверка форматирования, дат, спецблоков, подписей, ключевых элементов)
python test_parser.py

# Полный тест (обработка всего учебника DOCX и PDF)
python test_parser.py --full

# Тест с другим учебником и конфигурацией
python test_parser.py --docx books/8_klass_Vseobschaya_istoriya_.docx --config config_world_history.json
```

## Конфигурация

Конфигурационные файлы (`config_russia_history.json`, `config_world_history.json`)
содержат:

- **structure** — регулярные выражения для определения глав, параграфов, разделов,
  главных вопросов и синхронистических таблиц;
- **special_blocks** — маркеры специальных блоков;
- **formatting** — какие ключевые элементы извлекать (даты, термины, персоналии);
- **fonts** — соответствие шрифтов форматированию;
- **noise_patterns** / **footer_patterns** — паттерны для удаления «шума»
  (номера страниц, колонтитулы).

## Примечания

- **DOCX-парсер** — основной парсер. Использует `python-docx` для извлечения
  текста и форматирования (жирный, курсив, полужирный курсив). Определяет главы,
  параграфы, разделы, спецблоки и ключевые элементы по стилям и форматированию runs.
  Архитектура: единая основа `BaseDocxParser` (`base_docx_parser.py`) + отдельные
  парсеры для каждой книги (`parsers.py`). Если доработка универсальной логики
  ломает обработку ранее разобранных книг, для конкретной книги создаётся свой
  парсер, переопределяющий нужные методы (например, `collect_chapter_title`),
  с единой основой.
- **PDF-парсер** (`parser.py`) — fallback для PDF-файлов без DOCX-версии.
  Использует `pdfplumber` для извлечения текста и форматирования по имени шрифта
  (Bold, Italic, BoldItalic).
- **Фильтрация подписей к иллюстрациям** — DOCX-парсер автоматически отфильтровывает
  подписи к иллюстрациям (например, «Художник А. Кившенко», «Миниатюра из Лицевого
  летописного свода»), которые не являются частью учебного текста.
- **Гибкая структура параграфов** — DOCX-парсер обрабатывает разные варианты
  оформления параграфов: номер и название в одном заголовке («§ 1 Название»),
  номер отдельным параграфом («§ 10» + следующий заголовок), название без номера
  («§ Название»), а также заголовки, разбитые на несколько частей
  (например, «Англия, Франция...» + «в XI — начале XIV в.»).
- **Текст сохраняется без сокращений и перефразирования.**
- Функция `clean_text()` удаляет символы-артефакты (`\uf401`) из всего текста,
  включая термины, персоналии и даты.
