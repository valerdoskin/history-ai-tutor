# Промт: Адаптивный веб-интерфейс (комфорт на ПК и мобильных)

> **Дата:** 2026-09-02
> **Цель:** сделать веб-интерфейс (особенно окно с заданиями в тренировке по типам заданий)
> комфортным на разных устройствах — от широкого экрана ПК до узкого мобильного.
> Сейчас интерфейс жёстко оптимизирован под мобильное устройство, из-за чего на ПК
> окно с заданиями очень маленькое и узкое.

---

## Проблема (диагноз уже поставлен, НЕ перепроверять)

Веб-интерфейс собран как Telegram Web App и свёрстан под мобильный экран. Ключевая причина
узости на ПК — **жёсткая фиксированная ширина контейнера**:

- В `static/webapp.css` селектор `.app` (строка ~16) имеет `max-width: 480px; margin: 0 auto;`.
  Из-за этого на широком экране ПК весь интерфейс — узкая колонка 480px по центру, а окно
  с заданиями (вкладка «Практика» → «Тренировка по типам заданий») получается очень маленьким.
- В файле **нет ни одного `@media`-запроса** (только `max-width: 480px` у `.app` и
  `max-width: 85%` у `.message`). Значит, адаптивности под разные ширины нет вообще.
- Вкладки `.tabs` (6 кнопок: Чат, Практика, Темы, Карточки, Классы, Профиль) свёрнуты в одну
  строку и на узкой ширине тесные, а на широкой — растянуты на всю 480px-колонку.

## Файлы, которые нужно менять (только их)

1. `static/webapp.css` — основная работа (адаптивная вёрстка).
2. `templates/webapp.html` — только если потребуется добавить классы-обёртки/атрибуты
   (по возможности НЕ менять структуру HTML, решать через CSS).
3. `static/webapp.js` — НЕ менять (логика рендера вопросов не должна затрагиваться).

## Что нужно сделать

### 1. Сделать контейнер `.app` адаптивным по ширине
- Убрать жёсткое `max-width: 480px` (или заменить на адаптивную схему).
- На широких экранах (ПК) контейнер должен занимать разумную ширину (например,
  `max-width: 900–1100px`), а на мобильных — оставаться узким (вся ширина экрана).
- Сохранить центрирование (`margin: 0 auto`) и вертикальную структуру (`flex-direction: column`).

### 2. Добавить медиа-запросы для разных ширин
- **Мобильные (≤ 480px):** текущее поведение (узкая колонка, компактные отступы).
- **Планшеты (481–768px):** средняя ширина, чуть больше отступов.
- **ПК / десктоп (> 768px):** широкая колонка, крупнее шрифты и отступы, чтобы окно с
  заданием было просторным и читаемым.

### 3. Сделать окно с заданиями (тренировка по типам) просторным на ПК
Задания тренировки рендерятся в `#practice-content` (класс `.practice-content`) с внутренними
классами `test-card`, `test-question`, `test-options`, `test-option`, `test-source`,
`test-textarea`, `test-input`, `test-nav`, `test-progress`, `test-type-badge`, `train-badge`.
- На ПК карточка задания (`.test-card`) и текст вопроса (`.test-question`) должны занимать
  доступную ширину и не выглядеть «зажатыми».
- Убедиться, что `.practice-content` корректно прокручивается по вертикали при длинном
  вопросе/источнике (сейчас `overflow-y: auto`), и что карточка не обрезается.
- Проверить, что длинные тексты источников (`.test-source`) и развёрнутые ответы
  (`.test-textarea`) читаемы на широком экране.

### 4. Вкладки `.tabs` — адаптивность
- На узких экранах вкладки должны оставаться компактными (возможно, переноситься или
  прокручиваться по горизонтали).
- На широких экранах вкладки могут быть крупнее и равномерно распределены.

### 5. Не сломать остальные вкладки
Интерфейс использует общий контейнер `.app` для всех вкладок (Чат, Практика, Темы, Карточки,
Классы, Профиль). Убедиться, что изменение ширины `.app` не ломает:
- чат (`.chat-messages`, `.bubble` — сейчас `max-width: 85%`),
- списки тем/хронологии/личностей/терминов (`.topic-list`, `.chronology-list` и т.п.),
- карточки SRS (`.card-question`),
- тест уровня (`.placement-question`, `.placement-options`),
- полноценный тест (`.test-question`, `.test-options` — те же классы, что и в тренировке).

## Критерии приёмки (проверить в браузере)

1. **ПК (широкий экран):** окно с заданием в «Практика → Тренировка по типам заданий»
   занимает комфортную ширину (не узкая 480px-колонка), текст читается, карточка не обрезается,
   длинный источник/вопрос прокручивается корректно.
2. **Мобильный (узкий экран):** интерфейс остаётся компактным и удобным, как раньше.
3. **Все вкладки** (Чат, Практика, Темы, Карточки, Классы, Профиль) работают и выглядят
   корректно на обеих ширинах.
4. **Никаких горизонтальных скроллов** на ПК и мобильном.
5. **JS не менялся** — только CSS (и при необходимости минимальные правки HTML).

## Правила против зацикливания

- НЕ перечитывай `webapp.css`/`webapp.html` повторно после начала правок — работай по уже
  известной структуре (диагноз выше).
- НЕ меняй `static/webapp.js` и логику рендера.
- НЕ переписывай весь CSS — вноси точечные изменения и добавляй медиа-запросы.
- После правок проверь результат в браузере на двух ширинах (ПК и мобильный) и заверши работу.
