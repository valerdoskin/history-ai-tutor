# Промт-задание: определение страниц с картами в PDF-учебнике 5 класса

## Контекст

Проект **history-ai-tutor** — ИИ-репетитор по истории для подготовки к ОГЭ/ЕГЭ 2026.
В базе знаний `knowledge/maps.json` есть 188 записей о картах (название, период, класс,
описание, ключевые объекты). Задача — **показать изображение карты** в тренировке по картам.

Для этого нужно извлечь изображения карт из PDF-учебников. В PDF-учебнике 5 класса
(`books/5_klass_Istoriya_Drevnego_mira_.pdf`) карты могут быть:
- **растровыми изображениями** (извлекаются через `get_images()`),
- **векторной графикой** (извлекается через `get_drawings()`),
- **встроенными изображениями** (видны через `get_image_info()`, но не через `get_images()`).

Автоматический анализ (цвета, OCR) **не дал однозначного результата** — не удалось надёжно
отличить карты от иллюстраций. Поэтому нужна помощь человека.

## Что нужно сделать

Посмотрите на отрендеренные страницы параграфов в папке **`map_preview/`** и укажите,
**на каких страницах и в какой области находится карта** для каждой из 3 записей maps.json.

## Записи maps.json для пилота (3 шт.)

### 1. «Великая греческая колонизация» (класс 5)
- **Страницы параграфа в PDF:** 141–145
- **Файлы для просмотра:** `map_preview/greek_colonization_p141.png` … `p145.png`
- **Ключевые объекты (что должно быть на карте):** греческие колонии в Средиземноморье
  и Причерноморье (Сицилия, Южная Италия, побережье Чёрного моря), направления колонизации,
  метрополии (Афины, Коринф, Милет и др.).

### 2. «Походы Александра Македонского на Восток» (класс 5)
- **Страницы параграфа в PDF:** 199–203
- **Файлы для просмотра:** `map_preview/alexander_macedon_p199.png` … `p203.png`
- **Ключевые объекты:** Македония, Греция, Персидская держава, Египет, Месопотамия,
  Индия, направления походов Александра, места сражений (Граник, Исс, Гавгамелы).

### 3. «Завоевание Римом Италии» (класс 5)
- **Страницы параграфа в PDF:** 232–235
- **Файлы для просмотра:** `map_preview/rome_conquest_italy_p232.png` … `p235.png`
- **Ключевые объекты:** Рим, Италия, Самниты, этруски, галлы, греческие города Южной Италии,
  направления завоеваний Рима.

## Формат ответа

Для каждой записи укажите:

```
1. Великая греческая колонизация
   - Карта найдена: ДА / НЕТ
   - Страница(ы) PDF: <номер страницы>
   - Область карты на странице (примерные координаты в % от ширины/высоты страницы):
     x: от <..>% до <..>%, y: от <..>% до <..>%
   - Комментарий: <что изображено, есть ли подпись к карте>

2. Походы Александра Македонского
   ...

3. Завоевание Римом Италии
   ...
```

## Примечания

- Если на странице несколько изображений (карта + иллюстрации), укажите, **какое именно**
  изображение является картой (например, «верхняя половина страницы», «правая часть»).
- Если карта занимает всю страницу или её большую часть, так и укажите.
- Если карты в параграфе нет, укажите «НЕТ» — это тоже полезная информация.
- Координаты области нужны, чтобы вырезать карту из отрендеренной страницы без лишнего текста.
